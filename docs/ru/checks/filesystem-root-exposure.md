# Доступ к корню файловой системы

_Идентификатор проверки Gixy: `filesystem_root_exposure`_

Директивы NGINX [`root`](https://nginx.org/ru/docs/http/ngx_http_core_module.html#root)
и [`alias`](https://nginx.org/ru/docs/http/ngx_http_core_module.html#alias)
преобразуют пути запросов в пути файловой системы. Значение `/` делает корневой
каталог операционной системы базой этого преобразования:

```nginx
location / {
    root /;
}

location /files/ {
    alias /;
}
```

В зависимости от окружающих блоков `location` и правил доступа через HTTP могут
стать доступны конфиденциальные системные файлы. Gixy также обнаруживает постоянные
пути, сводящиеся к `/`, например `/srv/..` и `/./`. Пути с переменными не проверяются,
поскольку их значение во время выполнения нельзя определить статически.

## Как исправить?

Используйте отдельный каталог с узкой областью назначения:

```nginx
location / {
    root /var/www/example;
}

location /files/ {
    alias /srv/downloads/;
}
```

Убедитесь, что выбранный каталог содержит только предназначенные для публикации
файлы, и сохраните явные ограничения доступа для закрытых расположений.
